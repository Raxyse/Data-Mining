Repository ini berisi implementasi evaluasi model klasifikasi menggunakan Python dan scikit-learn. Fokus utama adalah membandingkan berbagai algoritma klasifikasi seperti Logistic Regression, Random Forest, k-NN, dan SVM dengan metrik evaluasi yang meliputi Accuracy, Precision, Recall, F1-Score, ROC Curve, serta AUC. Tujuan dari repository ini adalah memberikan gambaran menyeluruh tentang bagaimana menilai performa model secara adil dan komprehensif.
Repository ini juga dapat dijalankan dengan mudah. Setelah melakukan clone repository dan menginstal dependencies, pengguna dapat menjalankan script sesuai kebutuhan untuk melihat hasil evaluasi, validasi, maupun grafik ROC dan learning curve. Dengan demikian, repository ini dapat menjadi referensi praktis bagi mahasiswa maupun praktisi yang ingin memahami evaluasi model klasifikasi secara mendalam.
